# Colaboração

Como times trabalham juntos no código: estratégias de branch, mensagens de commit, revisão de PR e documentação técnica.

## Documentos

- **[Git Flow](./git-flow.md).** Modelo de branches (Driessen) e a alternativa moderna: Trunk-Based Development.
- **[Conventional Commits](./conventional-commits.md).** Formato `tipo(escopo): descrição` para automatizar changelog e versionamento.
- **[Pull Requests](./pull-requests.md).** PRs pequenos, descrição clara, modelo, comportamentos de autor e reviewer.
- **[Code review](./code-review.md).** Onde focar, severity tags, mentoria, anti-padrões. Princípios além do mecanismo.
- **[Documentação](./documentation.md).** Diátaxis (tutorial / how-to / reference / explanation), runbooks, postmortems, docs como código.
