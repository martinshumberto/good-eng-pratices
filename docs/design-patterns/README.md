# Padrões de Projeto

Catálogos clássicos de padrões: GoF (criacionais, estruturais, comportamentais) e enterprise patterns de Fowler. Vocabulário compartilhado para problemas recorrentes.

## Documentos

- **[Padrões criacionais](./creational.md).** Como objetos são instanciados. Factory, Builder, Singleton, etc.
- **[Padrões estruturais](./structural.md).** Como classes/objetos se compõem. Adapter, Decorator, Facade, Proxy, etc.
- **[Padrões comportamentais](./behavioral.md).** Interação e responsabilidade entre objetos. Strategy, Observer, Command, etc.
- **[Enterprise patterns (Fowler)](./enterprise-patterns.md).** Repository, Unit of Work, Active Record, Data Mapper, DTO, Money.
