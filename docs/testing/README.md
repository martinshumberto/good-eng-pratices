# Testes

Estratégia de testes em camadas: o que testar onde, como escrever, como verificar contratos entre serviços.

## Documentos

- **[Pirâmide de testes](./test-pyramid.md).** Muitos unitários, alguns de integração, poucos E2E. Trade-offs de custo × confiança.
- **[TDD e BDD](./tdd-bdd.md).** Red-green-refactor (Kent Beck) e especificação em linguagem natural (Dan North).
- **[Unit vs Integration vs E2E](./unit-vs-integration-vs-e2e.md).** Escopo, dependências reais, ferramentas, quando usar cada.
- **[Test doubles](./test-doubles.md).** Dummy, stub, spy, mock, fake. Classicist vs mockist (Fowler).
- **[Contract testing](./contract-testing.md).** Consumer-driven contracts via Pact. Alternativa a E2E entre serviços.
- **[Padrão AAA](./aaa-pattern.md).** Arrange, Act, Assert. Estrutura interna do teste.
