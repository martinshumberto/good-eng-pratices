# Fundamentos

Princípios universais que sustentam qualquer codebase: como nomear, separar, simplificar e proteger contra estados inválidos. Aplicáveis em qualquer linguagem e domínio.

## Documentos

- **[SOLID](./solid.md).** Cinco princípios de design OO: SRP, OCP, LSP, ISP, DIP.
- **[DRY, KISS, YAGNI](./dry-kiss-yagni.md).** Não repita, prefira o simples, não construa antes da necessidade.
- **[Coesão e acoplamento](./cohesion-coupling.md).** A métrica de design mais antiga e ainda mais útil.
- **[Funções puras](./pure-functions.md).** Determinísticas, sem efeito colateral. Base de código testável.
- **[Make Illegal States Unrepresentable (MISU)](./make-illegal-states-unrepresentable.md).** Use tipos para que estados inválidos não consigam existir.
- **[Code smells](./code-smells.md).** Sinais de problema de design. Vocabulário para conversas técnicas.
- **[Naming](./naming.md).** Nomes que revelam intenção. A documentação que não envelhece.
